# Art Gallery

Responsive gallery landing page for the neverdiephil DeviantArt archive.

## Features

- Desktop/tablet repeating 3D perspective gallery panels
- Flat movable-frame mobile composition
- Mobile per-tile parallax scrolling
- Internal tile vignette/gradient shadows
- Full-screen lightbox
- Swipe left/right on touch devices
- Mouse drag and keyboard arrow navigation
- Artwork resolved remotely through DeviantArt oEmbed
- No local artwork image files

## Files

- `index.html`
- `main.css`
- `artworks.js`
- `main.js`

Artwork source: https://www.deviantart.com/neverdiephil
