# 404 Pro Skater

A small browser endless-runner inspired by the feel of the classic offline dinosaur game, reimagined with a skateboarding dinosaur.

## Controls

- **Space / Up Arrow / Click / Tap:** Jump
- **P:** Pause

Each jump randomly performs one of three tricks:

- 360 Spin
- Kickflip
- Pop Shuvit

Long rails can appear at slightly different heights. Land on top of a rail to grind it for bonus points; hitting the side causes a wipeout.

## Files

- `index.html`
- `style.css`
- `game.js`

No build step or external dependencies are required.
